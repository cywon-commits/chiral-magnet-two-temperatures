task1_raw.tar        Task 1 (REPORT.md R-2..R-4): data/raw/t1_<proto>_D<D*100>_L<L>_s<seed>.npz, 56 runs
                     (anneal 52 = 7 D values x sizes x 4 seeds, quench 4) + task1_runs.json (per-run analysis output).
                     npz keys: T, dirn, E (per-sweep energy per spin incl. NEQ equilibration sweeps), Sk_rad, S0, Sk_low, cos4, e2,
                     acc, neq, nmeas, kc, ring_nq.  Generated by src/run_task1.py (seeds in src/jobs_task1.txt).
task2_pilot_raw.tar  Task 2 pilot (R-6): data/raw/t2_pilot_D<D*100>_L<L>_s1.npz, 7 runs + task2_pilot_runs.json.
                     npz keys: T, dirn, X (sum_bonds S_i.S_j per spin), Cb (sum_bonds r_ij.(S_i x S_j) per spin), Sk_rad, Sk_low,
                     cos4, e2, acc.  Generated by src/run_task2.py (v1, git history before commit f3a0501), jobs in src/jobs_task2_pilot.txt.
Restore: tar -xf <file> -C data/raw     Verify: sha256sum -c MANIFEST.txt

t2_main_D<D*100>_L<L>_s<seed>.tar  Task 2 main runs (REPORT.md R-7), one tar per run; checksums in MANIFEST_task2_main.txt.
  Contains t2_main_..._sN/  T<idx>_<T>.npz (one per temperature, 1.30 -> 0.31 step 0.03, 34 files) + DONE,
  and t2_main_..._sN.npz (angle-averaged summary, same keys as the pilot files).
  Per-temperature keys: T, E4 (per sweep incl. 1000 equilibration: S.S along x, S.S along y, x.(S_i x S_i+x), y.(S_i x S_i+y), per spin),
  Sdiag (3, L, L/2+1) float32 and Soff (3, L, L/2+1) complex64 = S_ab(k) = <F_a F_b*>/N on the rfft half plane (aa = xx,yy,zz; ab = xy,xz,yz),
  last (L, L, 3) float32 final configuration, samples (20, L, L, 3) float16 every 200 sweeps,
  moments (8, L, L, 8) float16: 500-sweep windows of (m_x, m_y, m_z, Qxx, Qyy, Qxy, Qxz, Qyz), Q traceless,
  plus Sk_rad, Sk_low, cos4, e2, acc, kc, ring_nq.  Generated by src/run_task2.py (v2, commit f3a0501), jobs src/jobs_task2_main.txt.
